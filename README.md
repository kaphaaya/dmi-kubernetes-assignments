# DevOps Micro Internship — Kubernetes Assignments (01–10)

A practical collection of Kubernetes assignments completed as part of the DevOps Micro Internship (DMI).

This repository documents hands-on exercises covering Kubernetes workloads, networking, storage, scaling, health checks and cloud-native application deployment.

## Assignments

| Assignment | Topic | Directory |
|---|---|---|
| 01 | Pods | `pods/` |
| 02 | ReplicaSets | `replicasets/` |
| 03 | Deployments | `deployments/` |
| 04 | Services | `services/` |
| 05 | Autoscaling | `autoscaling/` |
| 06 | Liveness Probes | `health-probes-liveness/` |
| 07 | Readiness Probes | `health-probes-readiness/` |
| 08–09 | Additional Kubernetes exercises | See available folders |
| 10 | Book Review Application on Amazon EKS | `book-review/` |

## Technologies and Tools

- Kubernetes
- Amazon EKS
- AWS CLI and eksctl
- Docker and Docker Hub
- Amazon EBS
- MySQL
- Nginx
- YAML
- kubectl

## Repository Structure

Each assignment has its own directory containing the relevant manifests, configuration files and supporting materials.

## Learning Objectives

- Deploy and manage Kubernetes workloads.
- Understand Pods, ReplicaSets and Deployments.
- Configure Kubernetes Services and networking.
- Implement health probes and autoscaling.
- Manage persistent storage.
- Deploy a multi-tier application on Amazon EKS.
- Troubleshoot Kubernetes and cloud infrastructure issues.
